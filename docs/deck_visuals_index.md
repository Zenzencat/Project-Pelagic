# Deck Visuals Index

Generated by `src/generate_deck_visuals.py`, which reads directly from `docs/checkpoint_comparison_summary.json`, `docs/confusion_matrix_breakdown.json`, and `docs/region_coverage.json` — no numbers retyped by hand. Re-run that script any time those exports change to regenerate all three images.

| File | What it shows | Answers which professor feedback |
|---|---|---|
| `docs/chart_v1_vs_v2_comparison.png` | Two-panel bar chart: IoU by category (v1 vs v2, showing bucket-level outcomes are essentially identical) + average false-positive area as % of scene (showing the real but modest v1→v2 improvement — 41.3%→37.5% for lookalike, not the earlier overstated 10-45% figure) | **"Better comparison slides"** |
| `docs/chart_confusion_matrix.png` | Heatmap grid: category (oil/no_oil/lookalike) × outcome (correct/partial/false positive/false negative), scene counts out of 10 each. Structurally-inapplicable cells (e.g. oil can never be bucketed "false positive" by the classifier's own definition) are marked "—", not "0", so a real checked zero is never confused with an inapplicable combination | **"More visuals"** — also directly supports the comparison-slide narrative alongside the v1-vs-v2 chart |
| `docs/chart_region_accuracy.png` | Horizontal bar chart: v2 pass rate by geographic region, sorted descending, with real scene counts (e.g. "11/15") labeled on each bar. Eastern Mediterranean and Sunda Strait pass well; Red Sea, Gulf of Mexico, Baltic Sea, and Western Mediterranean do not | **"Area of difference" / different places** — this is the direct visual for that ask, and one of the strongest results from the last few rounds that had no visual until now |

All three are static PNGs (matplotlib, already a project dependency) at 150 DPI — sized for dropping straight into a slide. None of this touches the live pipeline or app; same category as the existing per-scene overlay PNGs already in `docs/`.
